# Rådata fra statsregnskapet

Last opp «Rådata <måned> <år> (bevilgningsregnskap)» (xlsx) fra
https://statsregnskapet.dfo.no/last-ned her (Add file → Upload files). Oppdateringen
(`.github/workflows/oppdatering.yml`) starter da av seg selv, tar filen inn og publiserer
siden på nytt. En nyere måned erstatter den forrige for samme år; desemberfilen gir hele året.
